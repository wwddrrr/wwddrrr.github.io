# wwddrrr.github.io

Personal academic homepage, built with the [academic-homepage](https://github.com/luost26/academic-homepage) Jekyll template and served by GitHub Pages.

## Where to edit

| What | File |
| --- | --- |
| Name, positions, email, links, bio, photo, education, experience, awards | `_data/profile.yml` |
| Navigation bar | `_data/navigation.yml` |
| Homepage sections on/off | `_data/display.yml` |
| Publications / research items | `_publications/*.md` |
| News items | `_news/*.md` |

## Preview locally

Install Ruby and Jekyll ([instructions](https://jekyllrb.com/docs/)), then run `bundle exec jekyll serve` in this folder.
